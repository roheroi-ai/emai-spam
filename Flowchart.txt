

1. Data Ingestion
	Data: The Enron Email Dataset
	https://www.kaggle.com/datasets/mohinurabdurahimova/maildataset 
	Load into Pandas DataFrame.

2. Preprocessing
	
	Encoding.
	Data Cleaning.
	Tokenization.
	Stopword Removal.
	Stemming.
	TF-IDF Vectorization.
	Oversampling with SMOTE.

3.  Train-Test Split

4. Model Training

	DT
	NB
	RandomForest
	ETC
	MLP
	SVC
	VotingClassifier ( Combined all models )
	StackingClassifier ( Combined all models )
Extension : 
	VotingClassifier (different individual models)
	StackingClassifier (different individual models)

5. Evaluation
	Evaluate on test set using:
		Accuracy, Precision, Recall, F1-score, Confusion matrix to see false positives & negatives.
	XAI

6. Save the model

	Save the best performing model using Joblib.

7. Flask Web App


	Frontend (HTML):
	Input form for  features.
	Backend (Flask):
	Load saved model.
	Preprocess incoming features.
	Predict abnormalities.
	Return result to user.

Extension: 

As an extension we are going to implement the different combination Voting classifier and stacking classifier combining the individual models.
Along with that we are going to use XAI SHAP as another extension.
And also we used Flask Framework for UI for user provides input for prediction using trained models for dataset
